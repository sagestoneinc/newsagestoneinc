## Tracking Instructions

- Track rankings weekly, not daily, to avoid overreacting to normal search result volatility.
- Track Google and Bing separately if possible because rankings, indexing, and SERP features may differ by search engine.
- Use the target URL column to confirm the correct page is ranking for the keyword. If a different URL ranks, add that URL in the notes and decide whether internal links or content alignment should be adjusted.
- Add notes for content updates, backlinks, technical changes, indexing changes, sitemap submissions, title/meta updates, or material ranking shifts.
- Do not treat this tracker as a ranking guarantee. Use it to monitor trends and prioritize responsible content improvements over time.
